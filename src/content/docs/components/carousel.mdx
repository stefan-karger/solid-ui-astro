## About

The `Carousel` component wraps Embla Carousel and provides styled primitives for slides, content, and navigation controls.

## API Reference

### Core Parts

| Part               | Description                                                     |
| ------------------ | --------------------------------------------------------------- |
| `Carousel`         | Root wrapper that sets up Embla and carousel context.           |
| `CarouselContent`  | Viewport and flex track wrapper for slides.                     |
| `CarouselItem`     | Individual slide item.                                          |
| `CarouselPrevious` | Previous navigation button with built-in disabled behavior.     |
| `CarouselNext`     | Next navigation button with built-in disabled behavior.         |
| `useCarousel`      | Hook to access carousel context within carousel child elements. |

### Carousel

| Prop          | Type                                      | Default        |
| ------------- | ----------------------------------------- | -------------- |
| `opts`        | `EmblaOptionsType`                        | -              |
| `plugins`     | `EmblaPluginType[]`                       | `[]`           |
| `orientation` | `"horizontal" \| "vertical"`              | `"horizontal"` |
| `setApi`      | `(api: CarouselApi \| undefined) => void` | -              |

### Keyboard Interaction

When the carousel is focused, `ArrowLeft` moves to the previous slide and `ArrowRight` moves to the next slide.

See the [Embla Carousel docs](https://www.embla-carousel.com/api/options/) for all available options and plugins.
