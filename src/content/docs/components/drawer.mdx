## Usage

```tsx showLineNumbers
import { Button } from "~/components/ui/button"
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger
} from "~/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger as={Button} variant="outline">
    Open
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose as={Button} variant="outline">
        Cancel
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## API Reference

### Core Parts

| Part                | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `Drawer`            | Root component that controls open state and drag behavior.     |
| `DrawerTrigger`     | Interactive element used to open the drawer.                   |
| `DrawerContent`     | Sliding panel rendered in a portal.                            |
| `DrawerOverlay`     | Backdrop element behind the drawer content.                    |
| `DrawerHeader`      | Layout wrapper for title and description content.              |
| `DrawerTitle`       | Accessible heading for the drawer panel.                       |
| `DrawerDescription` | Supporting text that describes the drawer purpose.             |
| `DrawerFooter`      | Footer container for actions, usually submit and cancel.       |
| `DrawerClose`       | Interactive element used to close the drawer programmatically. |

### Common Root Props

| Prop                      | Type                                                 | Default    | Description                                      |
| ------------------------- | ---------------------------------------------------- | ---------- | ------------------------------------------------ |
| `side`                    | `"top" &#124; "right" &#124; "bottom" &#124; "left"` | `"bottom"` | The side the drawer opens from.                  |
| `open`                    | `boolean`                                            |            | Controlled open state.                           |
| `defaultOpen`             | `boolean`                                            | `false`    | Initial open state in uncontrolled mode.         |
| `onOpenChange`            | `(open: boolean) => void`                            |            | Called when open state changes.                  |
| `snapPoints`              | `Size[]`                                             | `[0, 1]`   | Positions the drawer can snap to while dragging. |
| `activeSnapPoint`         | `Size`                                               |            | Controlled active snap point.                    |
| `allowSkippingSnapPoints` | `boolean`                                            | `true`     | Allows skipping intermediate snap points.        |
| `closeOnOutsidePointer`   | `boolean`                                            | `true`     | Closes when pointer interaction happens outside. |
| `closeOnEscapeKeyDown`    | `boolean`                                            | `true`     | Closes when pressing the Escape key.             |

See the [Corvu Drawer documentation](https://corvu.dev/docs/primitives/drawer)
for the full API reference and behavior details.
