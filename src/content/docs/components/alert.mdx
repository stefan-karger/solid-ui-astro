## Usage

```tsx showLineNumbers
import { Alert, AlertDescription, AlertTitle } from "~/components/ui/alert"
```

```tsx showLineNumbers
<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app using the command line.</AlertDescription>
</Alert>
```

## Variants

Use the `variant` prop to emphasize critical states.

```tsx showLineNumbers
<Alert variant="destructive">
  <AlertTitle>Something went wrong</AlertTitle>
  <AlertDescription>Please review the highlighted fields and try again.</AlertDescription>
</Alert>
```

## Action

Use `AlertAction` when the message includes a related call to action.

```tsx showLineNumbers
import { Alert, AlertAction, AlertDescription, AlertTitle } from "~/components/ui/alert"
import { Button } from "~/components/ui/button"

function SecurityAlert() {
  return (
    <Alert>
      <AlertTitle>Two-factor authentication is off</AlertTitle>
      <AlertDescription>
        Enable 2FA to add an extra layer of protection to your account.
      </AlertDescription>
      <AlertAction>
        <Button size="xs" variant="outline">
          Enable
        </Button>
      </AlertAction>
    </Alert>
  )
}
```

## API Reference

### Core Parts

| Part               | Description                                               |
| ------------------ | --------------------------------------------------------- |
| `Alert`            | Root container for status content and optional icon.      |
| `AlertTitle`       | Primary alert heading.                                    |
| `AlertDescription` | Supporting message content.                               |
| `AlertAction`      | Positioned action slot for buttons or quick interactions. |

### Alert Props

| Prop      | Type                         | Default     |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `class`   | `string`                     |             |

All native `div` attributes are forwarded to the root element.
