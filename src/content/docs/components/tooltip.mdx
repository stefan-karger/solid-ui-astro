## Usage

```tsx showLineNumbers
import { Tooltip, TooltipContent, TooltipTrigger } from "~/components/ui/tooltip"
```

```tsx showLineNumbers
<Tooltip>
  <TooltipTrigger as="button">Hover or focus me</TooltipTrigger>
  <TooltipContent>Add to library</TooltipContent>
</Tooltip>
```

## Delay Duration

Use `openDelay` and `closeDelay` to control when the tooltip appears and disappears.

```tsx showLineNumbers
<Tooltip openDelay={250} closeDelay={100}>
  <TooltipTrigger as="button">Preview details</TooltipTrigger>
  <TooltipContent>Shows after a short delay.</TooltipContent>
</Tooltip>
```

## Positioning

Use `placement` and `gutter` to control where tooltip content is rendered.

```tsx showLineNumbers
<Tooltip placement="right" gutter={8}>
  <TooltipTrigger as="button">Right side</TooltipTrigger>
  <TooltipContent>Aligned to the trigger's right edge.</TooltipContent>
</Tooltip>
```

## Disabled

Set `disabled` on `Tooltip` to prevent it from opening.

```tsx showLineNumbers
<Tooltip disabled>
  <TooltipTrigger as="button">Will not open</TooltipTrigger>
  <TooltipContent>This content is never shown.</TooltipContent>
</Tooltip>
```

## API Reference

### Core Parts

| Part             | Description                                              |
| ---------------- | -------------------------------------------------------- |
| `Tooltip`        | Root component that controls tooltip state and behavior. |
| `TooltipTrigger` | Interactive element that opens tooltip content.          |
| `TooltipContent` | Floating content rendered in a portal near the trigger.  |

### Common Root Props

| Prop           | Type                      | Description                                           |
| -------------- | ------------------------- | ----------------------------------------------------- |
| `open`         | `boolean`                 | Controlled open state.                                |
| `defaultOpen`  | `boolean`                 | Initial open state in uncontrolled mode.              |
| `onOpenChange` | `(open: boolean) => void` | Called when the open state changes.                   |
| `openDelay`    | `number`                  | Delay before opening after pointer enter or focus.    |
| `closeDelay`   | `number`                  | Delay before closing after pointer leave or blur.     |
| `placement`    | `string`                  | Preferred floating placement such as `top` or `left`. |
| `gutter`       | `number`                  | Space in pixels between trigger and content.          |
| `disabled`     | `boolean`                 | Prevents tooltip behavior for the entire instance.    |

See the [Kobalte Tooltip](https://kobalte.dev/docs/core/components/tooltip)
documentation for all available props and behavior details.
