## Usage

```tsx showLineNumbers
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger
} from "~/components/ui/dialog"
```

```tsx showLineNumbers
<Dialog>
  <DialogTrigger as="button">Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>
        This action cannot be undone. This will permanently delete your account and remove your data
        from our servers.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

## API Reference

### Core Parts

| Part                | Description                                                   |
| ------------------- | ------------------------------------------------------------- |
| `Dialog`            | Root component that manages open state and focus behavior.    |
| `DialogTrigger`     | Interactive element used to open the dialog.                  |
| `DialogContent`     | Overlay + content container rendered in a portal.             |
| `DialogHeader`      | Layout wrapper for title and description content.             |
| `DialogTitle`       | Accessible heading for the dialog content.                    |
| `DialogDescription` | Supporting text that describes the dialog purpose.            |
| `DialogFooter`      | Footer container for actions, usually confirm/cancel buttons. |
| `DialogClose`       | Interactive element used to close the dialog.                 |

### Common Root Props

| Prop            | Type                      | Description                                      |
| --------------- | ------------------------- | ------------------------------------------------ |
| `open`          | `boolean`                 | Controlled open state.                           |
| `defaultOpen`   | `boolean`                 | Initial open state in uncontrolled mode.         |
| `onOpenChange`  | `(open: boolean) => void` | Called when open state changes.                  |
| `modal`         | `boolean`                 | Traps focus and blocks outside interaction.      |
| `preventScroll` | `boolean`                 | Prevents body scrolling while the dialog is open |

### DialogContent Props

| Prop              | Type      | Default | Description                                                  |
| ----------------- | --------- | ------- | ------------------------------------------------------------ |
| `showCloseButton` | `boolean` | `true`  | Controls whether the default top-right close button is shown |

See the [Kobalte Dialog](https://kobalte.dev/docs/core/components/dialog) documentation
for complete behavior details and all available props.
