## Usage

```tsx
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from "~/components/ui/resizable"
```

```tsx showLineNumbers
<ResizablePanelGroup direction="row" class="min-h-[200px] rounded-lg border">
  <ResizablePanel id="left-panel" initialSize={30}>
    Left panel
  </ResizablePanel>
  <ResizableHandle />
  <ResizablePanel id="right-panel" initialSize={70}>
    Right panel
  </ResizablePanel>
</ResizablePanelGroup>
```

## Vertical Layout

Set `direction="column"` on `ResizablePanelGroup` to switch to a vertical splitter.

```tsx showLineNumbers
<ResizablePanelGroup direction="column" class="min-h-[300px] rounded-lg border">
  <ResizablePanel id="top-panel" initialSize={40}>
    Top
  </ResizablePanel>
  <ResizableHandle />
  <ResizablePanel id="bottom-panel" initialSize={60}>
    Bottom
  </ResizablePanel>
</ResizablePanelGroup>
```

## Handle Styles

Use `withHandle` to render a visible drag grip.

```tsx showLineNumbers
<ResizableHandle withHandle />
```

## API Reference

### Core Parts

| Part                  | Description                                             |
| --------------------- | ------------------------------------------------------- |
| `ResizablePanelGroup` | Flex container that manages panel layout and direction. |
| `ResizablePanel`      | A resizable section identified by a unique `id`.        |
| `ResizableHandle`     | Draggable separator between adjacent panels.            |

### Common Props

| Part                  | Prop          | Type                                                     |
| --------------------- | ------------- | -------------------------------------------------------- |
| `ResizablePanelGroup` | `direction`   | `"row" \| "column" \| "row-reverse" \| "column-reverse"` |
| `ResizablePanel`      | `id`          | `string`                                                 |
| `ResizablePanel`      | `initialSize` | `number`                                                 |
| `ResizablePanel`      | `minSize`     | `number`                                                 |
| `ResizablePanel`      | `maxSize`     | `number`                                                 |
| `ResizableHandle`     | `disabled`    | `boolean`                                                |
| `ResizableHandle`     | `withHandle`  | `boolean`                                                |

See the
[solid-resizable-panels documentation](https://github.com/phgn0/solid-resizable-panels)
for full API details.
