## API Reference

### Core Parts

| Part        | Description                                            |
| ----------- | ------------------------------------------------------ |
| `Separator` | Divider element that supports horizontal and vertical. |

### Common Props

| Prop          | Type                         | Description                                             |
| ------------- | ---------------------------- | ------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | Sets the separator direction. Defaults to `horizontal`. |
| `decorative`  | `boolean`                    | Hides separator from assistive tech when purely visual. |
| `class`       | `string`                     | Adds custom styles to the separator element.            |

See the [Kobalte Separator](https://kobalte.dev/docs/core/components/separator) documentation for all available props.
