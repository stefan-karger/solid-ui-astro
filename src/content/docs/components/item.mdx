## Usage

```tsx showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle
} from "~/components/ui/item"
```

```tsx showLineNumbers
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

## Item vs Field

Use `Field` when a row represents form input controls such as checkbox, radio group, input, or select.

Use `Item` when you only need presentational content and optional actions.

## API Reference

### Item

Main row container for media, text content, and actions.

| Prop      | Type                                | Default     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size`    | `"default" \| "sm" \| "xs"`         | `"default"` |
| `as`      | `ValidComponent`                    | `"div"`     |
| `class`   | `string`                            | -           |

### ItemGroup

Container for grouping related item rows.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

```tsx showLineNumbers
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### ItemSeparator

Separator for dividing item rows in a group.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemMedia

Slot for media content such as icons, images, or avatar-like visuals.

| Prop      | Type                             | Default     |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |
| `class`   | `string`                         | -           |

### ItemContent

Wrapper for title/description regions.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemTitle

Primary text slot for item titles.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemDescription

Secondary text slot for supporting descriptions.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemActions

Container for action buttons and controls.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemHeader

Optional top section for full-width header content.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### ItemFooter

Optional bottom section for footer content.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
