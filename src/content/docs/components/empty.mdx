## Usage

```tsx showLineNumbers

  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle
} from "~/components/ui/empty"
```

```tsx showLineNumbers
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Icon />
    </EmptyMedia>

    </EmptyDescription>
```

## API Reference

### Empty

Root container for empty-state layout and centering.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### EmptyHeader

Top section for title, description, and optional media.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### EmptyMedia

Media slot for avatars, icons, or custom visuals.

| Prop      | Type                  | Default     |
| --------- | --------------------- | ----------- |
| `variant` | `"default" \| "icon"` | `"default"` |
| `class`   | `string`              | -           |

### EmptyTitle

Primary title text of the empty state.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### EmptyDescription

Supporting description text and optional inline links.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### EmptyContent

Action area for buttons, inputs, or additional helper content.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
