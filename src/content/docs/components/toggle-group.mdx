## API Reference

### Core Parts

| Part              | Description                                         |
| ----------------- | --------------------------------------------------- |
| `ToggleGroup`     | Root container that manages single/multiple select. |
| `ToggleGroupItem` | Toggle item that inherits group variant and size.   |

### ToggleGroup Props

| Prop           | Type                         | Default        | Description                                      |
| -------------- | ---------------------------- | -------------- | ------------------------------------------------ |
| `variant`      | `"default" \| "outline"`     | `"default"`    | Visual style applied to all group items.         |
| `size`         | `"default" \| "sm" \| "lg"`  | `"default"`    | Size applied to all group items.                 |
| `spacing`      | `number`                     | `0`            | Gap between items. `0` merges adjacent outlines. |
| `orientation`  | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction for group items.                |
| `multiple`     | `boolean`                    | `false`        | Enables multiple selected items.                 |
| `value`        | `string \| string[] \| null` | -              | Controlled selected value(s).                    |
| `defaultValue` | `string \| string[]`         | -              | Uncontrolled initial selected value(s).          |
| `onChange`     | `(value) => void`            | -              | Called when the selected value changes.          |
| `disabled`     | `boolean`                    | `false`        | Disables all items in the group.                 |
| `class`        | `string`                     | -              | Additional classes for the root element.         |

### ToggleGroupItem Props

| Prop      | Type                        | Default   | Description                            |
| --------- | --------------------------- | --------- | -------------------------------------- |
| `value`   | `string`                    | -         | Unique item value used for selection.  |
| `variant` | `"default" \| "outline"`    | inherited | Overrides group variant for this item. |
| `size`    | `"default" \| "sm" \| "lg"` | inherited | Overrides group size for this item.    |
| `class`   | `string`                    | -         | Additional classes for the item.       |

See the [Kobalte Toggle Group](https://kobalte.dev/docs/core/components/toggle-group)
documentation for complete behavior and all supported props.
