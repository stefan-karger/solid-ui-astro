## Usage

```tsx showLineNumbers
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuTrigger,
  navigationMenuTriggerStyle
} from "~/components/ui/navigation-menu"
```

```tsx showLineNumbers
<NavigationMenu>
  <NavigationMenuItem>
    <NavigationMenuTrigger>Guides</NavigationMenuTrigger>
    <NavigationMenuContent>
      <ul class="w-80 rounded-md bg-popover p-2">
        <li>
          <NavigationMenuLink href="/docs">Introduction</NavigationMenuLink>
        </li>
      </ul>
    </NavigationMenuContent>
  </NavigationMenuItem>
  <NavigationMenuItem>
    <NavigationMenuLink href="/docs" class={navigationMenuTriggerStyle()}>
      Documentation
    </NavigationMenuLink>
  </NavigationMenuItem>
</NavigationMenu>
```

## Link

Use `NavigationMenuLink` as a standalone item when no submenu content is required.

```tsx showLineNumbers
<NavigationMenuItem>
  <NavigationMenuLink href="/docs" class={navigationMenuTriggerStyle()}>
    Documentation
  </NavigationMenuLink>
</NavigationMenuItem>
```

## API Reference

### Core Parts

| Part                         | Description                                     |
| ---------------------------- | ----------------------------------------------- |
| `NavigationMenu`             | Root container that manages menu state.         |
| `NavigationMenuItem`         | Item container used for triggers and links.     |
| `NavigationMenuTrigger`      | Interactive control that opens submenu content. |
| `NavigationMenuContent`      | Floating content panel for each item.           |
| `NavigationMenuLink`         | Link element for direct navigation actions.     |
| `NavigationMenuIndicator`    | Visual indicator for the active trigger.        |
| `navigationMenuTriggerStyle` | Shared trigger classes for custom links.        |

See the
[Kobalte Navigation Menu](https://kobalte.dev/docs/core/components/navigation-menu)
documentation for complete props and behavior details.
