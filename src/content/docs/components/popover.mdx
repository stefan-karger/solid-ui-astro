## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "~/components/ui/popover"
```

```tsx showLineNumbers
<Popover>
  <PopoverTrigger as="button">Open</PopoverTrigger>
  <PopoverContent>Popover content</PopoverContent>
</Popover>
```

## Controlled State

Use `open` and `onOpenChange` for fully controlled behavior.

```tsx showLineNumbers
const [open, setOpen] = createSignal(false)

<Popover onOpenChange={setOpen} open={open()}>
  <PopoverTrigger as="button">Toggle</PopoverTrigger>
  <PopoverContent>Controlled popover content.</PopoverContent>
</Popover>
```

## Positioning

Use `placement` and `gutter` to control where content is rendered.

```tsx showLineNumbers
<Popover gutter={8} placement="bottom-start">
  <PopoverTrigger as="button">Bottom start</PopoverTrigger>
  <PopoverContent>Placed below and aligned to the trigger start.</PopoverContent>
</Popover>
```

## Anchor

Use `PopoverAnchor` to position content relative to a separate element.

```tsx showLineNumbers
<Popover>
  <PopoverAnchor class="inline-block rounded-md bg-muted px-3 py-2 text-sm">
    Anchor element
  </PopoverAnchor>
  <PopoverTrigger as="button">Open</PopoverTrigger>
  <PopoverContent>Anchored content.</PopoverContent>
</Popover>
```

## API Reference

### Core Parts

| Part                 | Description                                              |
| -------------------- | -------------------------------------------------------- |
| `Popover`            | Root component that manages open state and positioning.  |
| `PopoverTrigger`     | Interactive element used to toggle the popover content.  |
| `PopoverAnchor`      | Optional anchor for custom positioning targets.          |
| `PopoverContent`     | Floating content rendered in a portal near the trigger.  |
| `PopoverHeader`      | Layout helper for title and description blocks.          |
| `PopoverTitle`       | Accessible title for the content region.                 |
| `PopoverDescription` | Supporting description text for contextual information.  |
| `PopoverCloseButton` | Optional close control for dismissible content patterns. |

### Common Root Props

| Prop           | Type                      |
| -------------- | ------------------------- |
| `open`         | `boolean`                 |
| `defaultOpen`  | `boolean`                 |
| `onOpenChange` | `(open: boolean) => void` |
| `placement`    | `string`                  |
| `gutter`       | `number`                  |
| `modal`        | `boolean`                 |

See the [Kobalte](https://kobalte.dev/docs/core/components/popover) documentation for more information.
