## Usage

```tsx showLineNumbers
import { AspectRatio } from "~/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<div class="w-full max-w-md">
  <AspectRatio ratio={16 / 9} class="overflow-hidden rounded-lg border bg-muted">
    <img src="..." alt="..." class="h-full w-full object-cover" />
  </AspectRatio>
</div>
```

## Ratios

Use the `ratio` prop to set any custom proportion. For example, `ratio={1}` renders a square and
`ratio={3 / 4}` renders a portrait frame.

## API Reference

### Props

| Prop      | Type                            | Description                                                |
| --------- | ------------------------------- | ---------------------------------------------------------- |
| `ratio`   | `number`                        | Sets the width / height ratio. Defaults to `16 / 9`.       |
| `class`   | `string`                        | Adds custom styles to the root element.                    |
| `style`   | `string` or `JSX.CSSProperties` | Adds inline styles to the root while preserving the ratio. |
| `...rest` | `HTMLDivElement` attributes     | Forwards native `div` attributes to the root element.      |

This component is implemented with the native CSS `aspect-ratio` property.
