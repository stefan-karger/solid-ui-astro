
## Native Select vs Select

- Use `NativeSelect` for native browser behavior, better performance, or mobile-optimized dropdowns.
- Use `Select` for custom listbox behavior, richer keyboard interaction, and fully custom popup styling.

## API Reference

### Core Parts

| Part                   | Description                                            |
| ---------------------- | ------------------------------------------------------ |
| `NativeSelect`         | Wrapper around the native `select` element and icon.   |
| `NativeSelectOption`   | Individual option rendered as a native `option` node.  |
| `NativeSelectOptGroup` | Groups related options using native `optgroup` markup. |

### NativeSelect Props

| Prop    | Type              | Default     | Description                     |
| ------- | ----------------- | ----------- | ------------------------------- |
| `size`  | `"sm"\|"default"` | `"default"` | Select size variant.            |
| `class` | `string`          |             | Additional classes for wrapper. |

All native `select` props are forwarded.

### NativeSelectOption Props

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  |         |
| `disabled` | `boolean` | `false` |

### NativeSelectOptGroup Props

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `label`    | `string`  |         |
| `disabled` | `boolean` | `false` |
