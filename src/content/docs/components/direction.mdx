## Usage

```tsx
import { DirectionProvider } from "~/components/ui/direction"
```

```tsx showLineNumbers
<html lang="ar" dir="rtl">
  <body>
    <DirectionProvider direction="rtl">
      <App />
    </DirectionProvider>
  </body>
</html>
```

## useDirection

Use `useDirection()` to read the current direction from context.

```tsx showLineNumbers
import { useDirection } from "~/components/ui/direction"

const Example = () => {
  const direction = useDirection()

  return <div>Current direction: {direction}</div>
}
```

## API Reference

### Exports

| Name                | Description                                  |
| ------------------- | -------------------------------------------- |
| `DirectionProvider` | Provides direction context to child content. |
| `useDirection`      | Returns the current text direction.          |

### DirectionProvider

| Prop        | Type             |
| ----------- | ---------------- |
| `direction` | `"ltr" \| "rtl"` |
| `locale`    | `string`         |
| `children`  | `JSX.Element`    |

See the [Kobalte i18n utilities](https://kobalte.dev/docs/core/utilities/i18n) documentation for more details.
