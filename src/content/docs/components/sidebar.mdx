```tsx showLineNumbers

  Sidebar,
  SidebarContent,

  SidebarGroupContent,
```

## Sidebar Variants

The `Sidebar` component supports these variants:

- `sidebar` (default): attached to the edge of the viewport.
- `floating`: padded and visually detached from the viewport edge.
- `inset`: designed for layouts where the page content is wrapped with `SidebarInset`.

## Collapsible Modes

Use the `collapsible` prop to control behavior:

- `offcanvas` (default): slides in and out from the edge.
- `icon`: collapses to icon-only width.
- `none`: always visible and non-collapsible.

## Keyboard Shortcut

By default, users can toggle the sidebar with:

- `Cmd+B` on macOS
- `Ctrl+B` on Windows/Linux

## API Reference

### Core Parts

| Part                   | Description                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| `SidebarProvider`      | Context provider that stores open state and keyboard toggle behavior |
| `Sidebar`              | Main sidebar container and responsive behavior wrapper               |
| `SidebarInset`         | Main content container used with inset and standard layouts          |
| `SidebarHeader`        | Header region inside the sidebar                                     |
| `SidebarContent`       | Scrollable content area for groups and menus                         |
| `SidebarFooter`        | Footer region inside the sidebar                                     |
| `SidebarGroup`         | Group wrapper for related navigation items                           |
| `SidebarGroupLabel`    | Label for a sidebar group                                            |
| `SidebarGroupAction`   | Optional action button for a group label                             |
| `SidebarGroupContent`  | Content wrapper inside a group                                       |
| `SidebarMenu`          | Menu list container                                                  |
| `SidebarMenuItem`      | Individual menu item wrapper                                         |
| `SidebarMenuButton`    | Main interactive item in a sidebar menu                              |
| `SidebarMenuAction`    | Optional action button aligned to a menu item                        |
| `SidebarMenuBadge`     | Right-aligned badge for counts or status                             |
| `SidebarMenuSkeleton`  | Loading skeleton state for menu entries                              |
| `SidebarMenuSub`       | Nested submenu list                                                  |
| `SidebarMenuSubItem`   | Nested submenu item wrapper                                          |
| `SidebarMenuSubButton` | Interactive nested submenu item                                      |
| `SidebarInput`         | Sidebar-scoped input styling wrapper                                 |
| `SidebarSeparator`     | Sidebar-scoped separator styling wrapper                             |
| `SidebarTrigger`       | Button that toggles sidebar open/collapsed state                     |
| `SidebarRail`          | Interactive rail used to toggle the sidebar                          |
| `useSidebar`           | Hook for controlled/open/mobile sidebar state                        |

### SidebarProvider Props

| Prop           | Type                      | Default | Description                                |
| -------------- | ------------------------- | ------- | ------------------------------------------ |
| `defaultOpen`  | `boolean`                 | `true`  | Initial open state in uncontrolled mode    |
| `open`         | `boolean`                 |         | Controlled open state                      |
| `onOpenChange` | `(open: boolean) => void` |         | Callback fired when the open state changes |

### Sidebar Props

| Prop          | Type                                 | Default       | Description                    |
| ------------- | ------------------------------------ | ------------- | ------------------------------ |
| `side`        | `"left" \| "right"`                  | `"left"`      | Side where the sidebar appears |
| `variant`     | `"sidebar" \| "floating" \| "inset"` | `"sidebar"`   | Visual variant                 |
| `collapsible` | `"offcanvas" \| "icon" \| "none"`    | `"offcanvas"` | Collapse behavior              |

### useSidebar Return Value

| Property        | Type                                  | Description                             |
| --------------- | ------------------------------------- | --------------------------------------- |
| `state`         | `Accessor<"expanded" \| "collapsed">` | Current desktop visual state            |
| `open`          | `Accessor<boolean>`                   | Desktop open state                      |
| `setOpen`       | `(open: boolean \| updater) => void`  | Sets desktop open state                 |
| `openMobile`    | `Accessor<boolean>`                   | Mobile open state                       |
| `setOpenMobile` | `(open: boolean \| updater) => void`  | Sets mobile open state                  |
| `isMobile`      | `Accessor<boolean>`                   | Current mobile breakpoint status        |
| `toggleSidebar` | `() => void`                          | Toggles desktop or mobile sidebar state |
