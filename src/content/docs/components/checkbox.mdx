
```tsx showLineNumbers
<label class="flex items-center gap-2 text-sm">

```

## Controlled State

Use `checked` and `onChange` to fully control the checkbox state.

```tsx showLineNumbers
import { createSignal } from "solid-js"

import { Checkbox } from "~/components/ui/checkbox"

function NewsletterCheckbox() {
  const [checked, setChecked] = createSignal(false)

  return (
    <label class="flex items-center gap-2 text-sm">
      <Checkbox checked={checked()} onChange={setChecked} />
      Weekly newsletter
    </label>
  )
}
```

## Indeterminate State

Use `indeterminate` to represent a partial selection state.

```tsx showLineNumbers
<Checkbox checked={allSelected()} indeterminate={someSelected()} onChange={toggleAll} />
```

## API Reference

### Core Parts

| Part       | Description                                          |
| ---------- | ---------------------------------------------------- |
| `Checkbox` | Root checkbox primitive with built-in control markup |

### Checkbox Props

| Prop             | Type                         | Default |
| ---------------- | ---------------------------- | ------- |
| `checked`        | `boolean`                    |         |
| `defaultChecked` | `boolean`                    |         |
| `onChange`       | `(checked: boolean) => void` |         |
| `indeterminate`  | `boolean`                    | `false` |
| `disabled`       | `boolean`                    | `false` |
| `required`       | `boolean`                    | `false` |
| `name`           | `string`                     |         |
| `value`          | `string`                     | `on`    |
| `class`          | `string`                     |         |

All supported Kobalte root props are forwarded to the checkbox root.

See the [Kobalte Checkbox](https://kobalte.dev/docs/core/components/checkbox) documentation
for full behavior and accessibility details.
